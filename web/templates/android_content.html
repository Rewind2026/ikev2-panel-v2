在 Android 上的操作步骤

  1. 设置 → 网络和互联网 → VPN → 右上角 +
  2. 类型选 "IKEv2/IPSec MSCHAPv2"（Android 11-15 默认第一个选项）
  3. 按下表填写（不需要任何预共享密钥 PSK）
  4. 保存 → 点连接 → 通知栏出现钥匙图标 = 连上

连接参数

证书信任

Android 11+ 原生客户端 强烈建议 安装 CA 根证书（自签模式必须装，否则 server cert 校验会失败；LE 模式可跳过）：

  1. 下载 ca.cert.pem
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
  3. Android 7+ 会弹警告"网络流量可能被监视"——这是 CA 证书的通用提示，本面板自签 CA 受控可忽略

为什么不用 strongSwan app？

Android 11+ 系统设置的 IKEv2/IPSec MSCHAPv2 选项原生支持 EAP-MSCHAPv2 + 证书认证 （AOSP 源码 android.net.Ikev2VpnProfile.Builder.setAuthUsernamePassword）， 跟 iOS 17/18 的 mobileconfig 用同一套认证协议（eap-mschapv2）。 不装任何第三方 app 就能直接拨号。
