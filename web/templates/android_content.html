Android 上的步骤

  1. 设置 → 网络和互联网 → VPN → 右上角 +
  2. 类型选 「IKEv2/IPsec MSCHAPv2」（Android 11-15 默认就是第一个选项）
  3. 按下表填写（不需要任何预共享密钥 PSK）
  4. 保存 → 点连接 → 通知栏出现钥匙图标 = 连上

CA 证书信任

{{if .CertIncludeCA}}

自签模式：必须先装 CA 根证书，否则会报「证书不受信任」导致连接失败。

  1. 下载 ca.cert.pem
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
  3. Android 7+ 会弹警告「网络流量可能被监视」—— 这是 CA 证书的通用提示，本面板自签 CA 受控可忽略
  4. 装完后在 VPN 设置里把「CA 证书」选成刚装的那个

注意：Android 要求 CA 必须装到系统信任存储，装到「用户」凭据对 VPN 不生效。

{{else}}

Let's Encrypt 模式：无需安装任何 CA 证书。

本面板证书由 Let's Encrypt 签发，其根证书（ISRG Root X1）已内置在 Android 系统信任库中。 在 VPN 设置里把「CA 证书」一项保持留空即可 —— 填了反而可能因证书不匹配而连接失败。

{{end}}

strongSwan App 用户

如果你用的是 strongSwan App（而非系统原生），走的是另一条路：

  1. 下载本页的 .sswan 配置文件
  2. strongSwan App → 设置 → 导入配置 → 选该文件
  3. 导入后打开该连接，在密码框里手动输入密码（.sswan 不含密码）
  4. 确认「本地 ID」已填为用户名，否则服务端索要用户名时无从应答

注意：面板的二维码只对 iOS / macOS 有效（它下发的是 .mobileconfig， Android 无法解析）。Android 请用本页的 .sswan 或手工填参。

连接参数

手动填入 
# 名称（自定义）
name     = IKEv2 VPN

# 服务器（域名或 IP）
server   = {{.ServerAddr}}

# IPsec 标识符 = 用户名（EAP 预共享密钥标识）
ipsec_id = {{.User.Username}}

# 凭据
username = {{.User.Username}}
password = {{.User.Password}}

# CA 证书
ca_cert  = {{if .CertIncludeCA}}上面下载的 ca.cert.pem{{else}}留空（LE 模式）{{end}}

# 证书类型：留空或选「CA 证书」
#   （不要选「RSA 证书」，那会要求客户端证书，本面板是密码认证）
cert_type = (留空 / CA 证书)

# 服务器标识：留空或填 {{.ServerCN}}
#   （iOS 用的是这个值校验证书 CN）
server_id = {{.ServerCN}}

⚠️ 上方参数含该用户的明文密码，仅在受信任的设备上查看，用完请清空剪贴板。
