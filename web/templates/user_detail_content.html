客户端配置

iOS / macOS

用 Safari 打开链接 → 设置 → 通用 → VPN 与设备管理 → 安装描述文件。

下载 .mobileconfig

Android 11+ 系统原生

无需第三方 app。

  1. 设置 → 网络和互联网 → VPN → 添加 VPN
  2. 类型选 IKEv2/IPsec MSCHAPv2
  3. 按 此处参数 填入 server / CN / 用户名 / 密码
  4. 保存 → 连接

Android strongSwan app

用于旧版 Android 或需要更精细控制。

下载 .sswan 配置

导入 strongSwan app → 添加 profile → 选择 .sswan 文件。(不含密码 — app 需手动输入)

Linux strongSwan

命令行客户端配置。

下载 .sswan 配置
Install 
# 1. 复制到 swanctl 配置目录
$ sudo cp {{.User.Username}}.conf /etc/swanctl/conf.d/
# 2. 加载所有配置
$ sudo swanctl --load-all
# 3. 启动连接
$ sudo swanctl -i {{.User.Username}}

CA 证书

Android 原生 / strongSwan app / Linux 客户端都要先装 CA 证书才能验证服务器身份。

下载 ca.cert.pem

Android 需要单独安装 CA 证书;iOS / macOS 已通过 .mobileconfig 自动安装。
