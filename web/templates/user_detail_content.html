客户端配置

iOS / macOS

用 Safari 打开链接 → 设置 → 通用 → VPN 与设备管理 → 安装描述文件。

下载 .mobileconfig
{{/* P1-1: 校验失败跳回来时展开 details,并把用户填的值回填进表单。 details 默认折叠 —— 不展开的话,顶部 banner 说"保存失败",而表单还 收在折叠区里,用户会以为没保存并重复提交。 */}}
⚙️ 高级选项（每用户描述文件覆盖）

这些参数只影响本用户下载的 .mobileconfig，不影响其他人。 修改后下次扫码 / 下载自动生效，无需重新配置服务端。 优先级：本用户覆盖 > 管理员全局默认 > 出厂。 想改所有用户的默认值，到 配置 → 描述文件默认值。

{{$o := .MCOpts}}

注意：上方「所有流量都走 VPN」开启时，iOS 会接管包括局域网在内的全部流量， 本项按 Apple 语义不再产生实际差异。想保留打印机 / NAS / 路由器管理页， 需关闭「所有流量都走 VPN」。

仅影响本用户描述文件里的 DNS 列表。服务端 ModeConfig 推送的 DNS 不受此处影响 （当前为 1.1.1.1 / 8.8.8.8 / 2606:4700:4700::1111 / 2001:4860:4860::8888）。

仅客户端侧生效。服务端 DPD 固定为 dpd_delay=30s / dpd_timeout=120s，不可调； 选 None 只关闭客户端主动探测。

Android 11+ 系统原生

无需第三方 app。

  1. 设置 → 网络和互联网 → VPN → 添加 VPN
  2. 类型选 IKEv2/IPsec MSCHAPv2
  3. 按 此处参数 填入 server / CN / 用户名 / 密码
  4. 保存 → 连接

Android strongSwan app

用于旧版 Android 或需要更精细控制的场景。

下载 .sswan

导入 strongSwan app → 添加 profile → 选择 .sswan 文件。（文件不含密码，需在 app 里手动输入）

Linux strongSwan

命令行客户端配置。

下载 .sswan
安装步骤 
# 1. 复制到 swanctl 配置目录
$ sudo cp {{.User.Username}}.conf /etc/swanctl/conf.d/
# 2. 加载所有配置
$ sudo swanctl --load-all
# 3. 启动连接
$ sudo swanctl -i {{.User.Username}}
