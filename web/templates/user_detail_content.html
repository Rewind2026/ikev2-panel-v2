客户端配置

iOS / macOS

用 Safari 打开链接 → 设置 → 通用 → VPN 与设备管理 → 安装描述文件。

下载 .mobileconfig
{{/* v2.86-PR12.21:mobileconfig 高级选项(每用户覆盖) */}}
⚙️ 高级选项(每用户 mobileconfig 覆盖)

这些参数只影响本用户下载的 .mobileconfig,不影响其他人。 修改后下次扫码 / 下载自动生效,无需重新配置服务端。 优先级:本用户 overlay > 管理员全局默认 > 出厂。 想改所有用户的默认值,到 管理员后台 → 配置 → Mobileconfig 默认值。

📖 说明: AuthPasswordRetries 字段在 iOS 官方文档中并不存在(已在 v2.86-PR12.22 audit 中移除);EAP 失败重试由客户端 OS 内部决定。

📖 参数说明
  • 连接显示名:iOS 设置 → VPN 列表里显示的名字,留空用默认 "IKEv2 VPN"。
  • 按需连接场景:5 个预设,见上方 select 提示。改完后 home_wifi_disconnect 必填 SSID。
  • 睡眠时断开:默认 否(锁屏保活,推送及时)。想省电改 是。
  • NAT 保活:默认开启。运营商 NAT 过期会踢掉 VPN,启用后硬件网卡持续发 keepalive。
  • NAT 保活间隔:默认 60 秒。国内运营商 NAT 寿命 ~120s,建议保持 60;国外 ~30s 改 25。
  • 全局路由:默认 是(所有流量进 VPN)。改 否 后部分流量直连(split tunnel),适合想用内网服务的场景。
  • 排除局域网:默认 是(192.168.x.x 路由器管理页面等仍可访问)。
  • DNS 服务器:隧道内 DNS 解析器。改用内网 DNS / AdGuard / NextDNS 都能填。
  • EAP 密码重试:默认 3 次。改成 1 可以让密码错时快速失败,不阻塞用户。
  • DPD 心跳:检测对端存活。Wi-Fi 信号差选 Low;企业网选 High。

⚠️ 没开放的字段(算法/DH 群/PFS/MTU/证书 CN/EAP 模式等)跟服务端 strongSwan 绑死, 改一边 = VPN 起不来。这是有意设计,避免误操作。

Android 11+ 系统原生

无需第三方 app。

  1. 设置 → 网络和互联网 → VPN → 添加 VPN
  2. 类型选 IKEv2/IPsec MSCHAPv2
  3. 按 此处参数 填入 server / CN / 用户名 / 密码
  4. 保存 → 连接

Android strongSwan app

用于旧版 Android 或需要更精细控制。

下载 .sswan 配置

导入 strongSwan app → 添加 profile → 选择 .sswan 文件。(不含密码 — app 需手动输入)

Linux strongSwan

命令行客户端配置。

下载 .sswan 配置
Install 
# 1. 复制到 swanctl 配置目录
$ sudo cp {{.User.Username}}.conf /etc/swanctl/conf.d/
# 2. 加载所有配置
$ sudo swanctl --load-all
# 3. 启动连接
$ sudo swanctl -i {{.User.Username}}

CA 证书

Android 原生 / strongSwan app / Linux 客户端都要先装 CA 证书才能验证服务器身份。

下载 ca.cert.pem

Android 需要单独安装 CA 证书;iOS / macOS 已通过 .mobileconfig 自动安装。
