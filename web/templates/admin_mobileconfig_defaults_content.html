📖 参数说明(同用户详情页"高级选项")
  • 连接显示名:iOS 设置 → VPN 列表里显示的名字。留空用 "IKEv2 VPN"。
  • 按需连接场景:5 个预设,见 select。注意 home_wifi_disconnect 需要每用户填 SSID(SSID 是 per-network 的,不能全局)。
  • 睡眠时断开:默认 否(锁屏保活,推送及时)。改 是 省电但推送延迟。
  • NAT 保活:默认开启,运营商 NAT 过期会踢掉 VPN,启用后硬件网卡持续发 keepalive。
  • NAT 保活间隔:默认 60 秒。国内运营商 NAT 寿命 ~120s,建议保持 60;国外可改 25。
  • 全局路由:默认 是(所有流量进 VPN)。改 否 部分流量直连(split tunnel)。
  • 排除局域网:默认 是(192.168.x.x 路由器管理页面等仍可访问)。
  • DNS 服务器:隧道内 DNS 解析器。改用内网 DNS / AdGuard / NextDNS 都能填。
  • EAP 密码重试:默认 3 次。改 1 让密码错时快速失败,不阻塞用户。
  • DPD 心跳:检测对端存活。Wi-Fi 信号差选 Low;企业网选 High。

⚠️ 没开放的字段(算法/DH 群/PFS/MTU/证书 CN/EAP 模式等)跟服务端 strongSwan 绑死, 改一边 = VPN 起不来。这是有意设计,避免误操作。
